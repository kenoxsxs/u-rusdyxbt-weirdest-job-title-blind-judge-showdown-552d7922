## The entry

One job title, 56 characters, 8 words:

> Senior Apologizer for Elevators That Stop Between Floors

A real-sounding job with one hilariously specific twist: a senior
apologizer whose whole career is saying sorry to people trapped in
elevators that stop between floors.

## How it works

`main.py` writes the title to `/output/entry.txt` and nothing else.
It verifies the title first (shape, words, letters, substrings,
structure, the elevator arc, the job itself, the voice, the
neighbours, the bytes), writes it directly to the target file,
reads it back, verifies it again, and seals the output folder so
it holds only `entry.txt`.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
```
